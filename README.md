
# Python Calculator

A calculator application built with Python as part of my programming journey.

## Features

- Performs calculations using a graphical interface.
- Practises Python programming and problem-solving and GUI development.

## Technologies Used

- Python
- Tkinter

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the Python file:

```bash
python tkinter_calculator.py
```
